# 🚀 TyperX

Keyron is a typing-training game built with Python and Pygame. It combines gaming and learning to help users improve typing speed, keyboard accuracy, and reaction time through multiple interactive game modes.

## 🎮 Features

### Typing Survival

* Destroy falling words by typing them correctly.
* Progress through multiple levels.
* Face powerful Boss battles that require typing complete sentences.
* Increasing difficulty as levels advance.

### Keyboard Reflex Trainer

* Individual letters fall from the top of the screen.
* Press the correct key before the letter reaches the bottom.
* Improve keyboard familiarity and reaction speed.
* Unlock higher levels by reaching score targets.

### Precision Typing Mode

* Type words, phrases, or sentences without making a single mistake.
* One incorrect key press results in an instant Game Over.
* Focus on perfect accuracy and concentration.
* Compete against your best records.

## 📚 Custom Training Text

Users can:

* Paste their own text.
* Load text files.
* Train using vocabulary relevant to their studies, work, or interests.

The game automatically extracts words and sentences from the provided text and uses them during gameplay.

## 📈 Progress Tracking

* Persistent save system.
* Difficulty-specific progression.
* Statistics dashboard.
* High scores and personal records.

## 🎯 Difficulty Levels

### Beginner

* Slower gameplay.
* Shorter words.
* Easier progression.

### Medium

* Balanced challenge.
* Faster enemies.
* More complex words.

### Hard

* High speed gameplay.
* Advanced vocabulary.
* Greater challenge and intensity.

## 🛠 Technologies

* Python
* Pygame
* SQLite

## 🎯 Project Goal

Keyron was created to transform typing practice into an engaging and rewarding experience. Instead of repetitive exercises, players learn through challenges, progression systems, and game mechanics designed to improve both speed and accuracy.
